# 猫导知识库使用规则

当用户的任务属于下面任意一类时，**先调用 `maodao_kb`**，再给方案：

- 写短视频口播脚本、标题、开头钩子、分镜文案；
- 问「怎么起号」「怎么留人」「怎么提高转化」「这个开头怎么写」「怎么投」；
- 要拆解/模仿某类爆款的内容结构；
- 用户明确提到「猫导」「借势」「金句」等方法论。

不要在这些场景调用：

- 只是剪辑操作（裁剪、拼接、转场、调色、字幕时间轴）→ 用视频编辑工具；
- 问「这个视频里第几秒有什么」→ 用 `video_rag_search`，不是 `maodao_kb`；
- 纯寒暄或与内容创作无关的问题。

## 调用方式

```
maodao_kb(query="用户原话或一句具体问题", k=4)
```

如果用户明显在某个垂直领域（如「投流」「直播」「公众号」），可以传 `domains`；不确定就不传，让猫导侧自动路由。

## 拿到结果后

- 把它当**自己的判断依据**，用来给建议、补方法、卡标准；
- **不要照背原文**，不要说「课程里说」「某位老师讲」；
- 和用户的实际行业/素材/预算对不上时直接丢掉，不要为了用知识而硬套；
- 如果工具返回「没有找到足够相关的知识」或「知识库不可用」，就按你自己的判断继续，**不要编造引用**，也不要声称查过知识库。
