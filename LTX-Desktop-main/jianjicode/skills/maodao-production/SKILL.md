# 猫导制作计划使用规则

当用户要「一条视频怎么拍」「给个脚本/分镜/镜头表」「新店开业拍什么」「这条怎么拆镜头」时，
**先调用 `maodao_plan`**，拿猫导生成的结构化镜头表，再谈素材和剪辑。

## 先确认两件事

调用前必须有：

- `topic`：这条视频想讲什么（尽量用用户原话）；
- `product`：推广的产品 / 服务 / 门店。

缺一个就先问，不要替用户编主题或产品。其余参数可选：

| 参数 | 说明 |
|---|---|
| `platform` | 默认抖音 |
| `duration` | 总秒数，15–120，默认 40 |
| `scenes` | 镜头数，2–8，默认 4；且需满足 `3×scenes ≤ duration ≤ 30×scenes` |
| `audience` | 目标受众，会映射成猫导的 targetCustomer |
| `must_include` | 必须出现的信息，最多 5 条 |
| `avoid` | 要避开的红线，最多 5 条 |

`style` 目前只支持 `剧情`。用户要口播稿，应走文案生成 / `maodao_kb`，不要用本工具。

## 调用方式

```
maodao_plan(
  topic="健身房新店开业，想让人来体验",
  product="9.9 元私教体验课",
  duration=40,
  scenes=4,
  audience="25-40 岁上班族",
  must_include=["门店地址"],
)
```

## 拿到镜头表后

1. 先用**表格或编号列表**把镜头表复述给用户：每镜的秒数、景别、画面、旁白；
2. 标出 `warnings`（例如模型给的总时长和请求不一致），不要藏；
3. 问用户下一步要做什么：补素材、改某一镜、还是进时间线。**不要自动开始生成视频**；
4. 用户要改某一镜时，优先在原镜头表上改，不要重新调一次 `maodao_plan` 把整条推翻。

## 失败时

工具返回 `error: true`（未配置令牌、超时、额度用完、模型没答好）时：

- **明确告诉用户这一轮没有拿到镜头表**，并给出原因；
- **不要自己临时编一份分镜冒充猫导结果**；
- 配额/超时可以让用户稍后重试；未配置令牌要提示去 `config.json` 的
  `maodaoProduction.token` 或环境变量 `MAODAO_PROD_TOKEN` 配置。

## 与其它工具的分工

- 问方法论、为什么这么写 → `maodao_kb`；
- 要一份具体分镜 → `maodao_plan`；
- 问「这个视频第几秒有什么」→ `video_rag_search`；
- 纯剪辑操作 → 视频编辑工具。

## 配音

需要给镜头表配音时调用：

```
maodao_tts(
  segments=[
    {id="s1", text="第一镜旁白"},
    {id="s2", text="第二镜旁白"},
  ],
  voice="Cherry",
)
```

规则：

- `id` 用镜头号（`s1`、`s2`…），只能字母/数字/`_`/`-`，最多 32 位；
- 单段最多 600 字，总计最多 3000 字，一次最多 20 段；
- 只把 `voiceover` 非空的镜头送去配音，空旁白跳过；
- 成功后会返回每段本地路径和时长，**优先用音频时长排时间线**，没有音频才用镜头表里的 `seconds`；
- 任一段失败会整单失败、不留半套音频。此时不要反复重试烧额度；
  应明确告诉用户「配音不可用」，并退回无配音时间线。

猫导 DashScope 欠费时 TTS 会直接失败；这属于外部服务不可用，不是参数错。
